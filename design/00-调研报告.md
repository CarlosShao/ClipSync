## 1. 产品全景

ClipSync 是一款**跨设备剪贴板同步工具**：手机复制 → 电脑秒粘（反之亦然）。

| 端 | 技术 | 说明 |
|----|------|------|
| 桌面端 | Tauri 2（Rust + WebView） | Windows / macOS / Linux，全局快捷键、快速粘贴浮层 |
| 移动端 | Flutter 3.x | Android 优先（国内分发），iOS 计划中 |
| 后端 | Node.js 22 + Express 5 + ws | 单体服务，REST + WebSocket |
| 存储 | PostgreSQL + Redis | 会话/黑名单/限流用 Redis |
| 加密 | AES-256-GCM 端到端加密 | 服务端只存密文（`content_encrypted`），服务端不可读内容 |

**核心功能**（官网文案与后台看板的事实来源）：
- 实时剪贴板同步（WebSocket 推送）
- 端到端加密（隐私数据服务器不可见）
- AI 智能分类（验证码/链接/代码/图片自动识别）
- 历史记录（搜索、收藏、收藏夹层级、自动过期）
- 文件/图片同步（≤50MB，分块上传）
- 模板与模板变量、共享链接、离线队列
- 深色模式 / 多语言（l10n）

**线上形态**：域名 `api.clipchain.top`（见 `docs/product/payment-integration-guide.md` 的回调地址）；部署用 docker-compose（dev/prod/multi 三套）+ nginx 反代 + Prometheus/Grafana 监控（`docker-compose.monitoring.yml`）。

## 2. 后端现状盘点（对后台系统最有利的部分：地基已打好）

### 2.1 数据库（42 个迁移，`src/server/src/db/migrations/`）

核心表：

| 表 | 要点 |
|----|------|
| `users` | 手机号唯一；`phone_encrypted/phone_hash`（可搜索加密）；`subscription_status`；`is_admin`；`role_id`；`is_active`（停用位）；合规字段（tos/privacy/marketing_consent） |
| `devices` | user_id 外键；device_type（desktop/mobile/tablet/browser）+ platform；public_key（E2E 密钥交换）；is_online / last_seen_at |
| `clipboard_items` | 内容密文 + preview + content_type（text/image/file/link/code）+ expires_at |
| `user_sessions` | 会话表（jti 绑定），可吊销（is_active / revoked_at） |
| `verification_codes` | 验证码（当前 MVP 固定码 888888，真实短信通道未接） |
| `subscription_plans` | Free / Pro（¥9.9 月、¥99 年）/ Enterprise（¥19.9 月、¥199 年）；配额字段：max_devices / max_clipboard_items / max_file_size_mb / max_storage_mb；features JSONB |
| `user_subscriptions` | 状态机 active/canceled/past_due/expired；billing_cycle；auto_renew；stripe_subscription_id / alipay_agreement_id / wechat_pay_prepay_id |
| `payment_orders` | 金额 + currency(CNY) + 状态机 pending/paid/failed/cancelled/refunded；order_no / out_trade_no / transaction_id |
| `invoices` | 发票抬头/税号；pdfkit 生成 PDF |
| `audit_logs` | user_id / action / resource_type / resource_id / details JSONB / ip / UA / status；**1 年自动清理函数已建** |
| `roles` / `permissions` / `role_permissions` | RBAC 三件套（迁移 028） |
| `system_configs` / `feature_flags` | 管理面配置 + 功能开关（迁移 038，已带种子数据） |
| `usage_stats`、`two_factor`、`surveys`、`templates`、`shared_links`、`ai_providers`、`ai_conversations`、`ai_memories`、`workflow_rules` 等 | 功能支撑表 |

### 2.2 认证与 RBAC（`src/middleware/auth.js`、`028_roles.sql`、`037_super_admin_protection.sql`）

- JWT Bearer + 会话绑定（jti）+ Redis 黑名单 + `user_sessions.is_active` 双兜底；支持**会话级吊销**（后台可直接复用）。
- 密码登录（bcryptjs）+ 验证码登录 + 邮箱验证码（nodemailer）+ 2FA TOTP + refresh token。
- **RBAC 已建**：`super_admin`(100) / `admin`(50) / `user`(10)，`req.user.roleKey/roleLevel/isAdmin` 每请求注入；超管唯一性由 DB 触发器强制；`is_admin` 布尔仅作兼容。
- **超管审计中间件已建**（`superAdminAudit.js`）：super_admin 的所有写操作自动落审计，body 脱敏。
- 规划文档 `docs/todo/MISSING_FEATURES_DESKTOP.md` 第三节明确了权限目录方向：`admin.users / admin.devices / admin.subscriptions / admin.audit / admin.keys / admin.roles + ai.scope`。

### 2.3 支付（`src/routes/payments.js`、`subscriptions.js`、`invoices.js`）

- 已有：创建订单、订单状态查询、微信/支付宝/Stripe 三个 Webhook（签名校验 + 幂等中间件，当前 **Mock 态**，等商户号）、退款（`POST /api/payments/refund`）、对账（`GET /api/payments/reconciliation`）、发票列表/PDF 下载、订阅创建/取消/恢复、7 天 Pro 试用、到期降级。
- 套餐配额中间件 `subscriptionCheck.js` + `planLimits.js` 已在主链路上生效。
- 支付渠道规划：微信支付（国内主）、支付宝（国内备）、Stripe（国际）；Apple IAP 搁置。

### 2.4 现有管理能力缺口

- 全部 API 中仅有 1 个管理端点：`GET /api/admin/slow-queries`（慢查询）。
- `docs/production-roadmap/phases-11-15.md` 阶段十四明确规划了管理后台（用户管理、订阅管理、系统健康 UI、审计日志查看器、公告、维护模式、功能开关、按套餐限速），状态全部"未开始"。
- `docs/todo/MISSING_FEATURES_DESKTOP.md` 第三节列了后台能力清单（RBAC P1、用户/设备管理 P1、登录历史 P1、审计查看器 P0、会话撤销 P0、密钥管理 P1、订阅/支付管理 P1、通知运营 P2、API Key/Webhook P2）。
- **结论：本次开发就是把既有规划 + 数据地基正式落地，不是从零造轮子。**

## 4. 部署与运维约束

- 后端以 Docker 跑（dev 环境 `docker-compose.dev.yml`），Node 22 单实例 + nginx 反代；有 k8s 目录（base/overlays）但主线是 compose。
- 监控已有 Prometheus + Grafana + Alertmanager（`docker-compose.monitoring.yml`、`monitoring/`）。
- 外部依赖待接入：短信服务商（当前验证码 Mock）、微信/支付宝/Stripe 商户、对象存储（当前本地 `uploads/`）。
- 低并发（后台仅管理员使用）——方案明确**不引入**限流、分库分表、消息队列等复杂度。

---

## 5. 对两个新工程的关键结论

1. **后台系统后端直接扩展现有 Express 服务**（新增 `/api/admin/*` 路由组），复用 JWT、RBAC、audit_logs、system_configs、feature_flags——不新建服务。
2. **后台前端是全新独立 SPA**，部署为静态资源由 nginx 托管（如 `admin.clipchain.top`）。
3. **官网是纯静态站**（后端零依赖或仅表单转发），独立仓库/目录部署。
4. 品牌色以移动端 `#5A4BD1` 为准，官网与后台共用一套品牌 token。
5. 官网文案可用的硬事实：E2E 加密、AI 分类、50MB 文件、多平台、订阅价格（Free/¥9.9/¥19.9）。
