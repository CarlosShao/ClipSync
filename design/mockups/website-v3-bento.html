常见问题

端到端加密下换新手机，数据怎么办？＋
新设备扫码配对通过加密握手接入，历史记录以密文同步（按套餐上限）；旧设备可随时移除，密钥即刻失效。
免费版够用吗？＋
核心同步与加密能力免费完整可用（2 台设备、50 条历史）。如果你需要多设备、大文件与全文搜索，Pro 是大多数人升到的档位。
支持 iOS 吗？＋
iOS 在路线图中。当前 Windows / macOS / Linux / Android 已就绪，订阅在所有端通用。
如何取消订阅？＋
客户端「订阅」页一键取消，当期结束前仍可继续使用，之后自动回到 Free，数据不删除。
