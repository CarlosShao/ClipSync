FEATURES

不只是同步，
是给剪贴板装上记忆与判断力

从一条文本到一部手机的相册，ClipSync 处理的是你每天复制粘贴的完整流。

实时同步

基于 WebSocket 的毫秒级推送。手机上按下复制，电脑剪贴板在同一瞬间完成更新——没有「刷新」，没有「手动发送」。

AI 智能分类

自动识别验证码、链接、代码、地址与图片。验证码类内容会置顶并加急提醒，重要内容不再淹没在历史里。

历史与全文搜索

最多保留 5,000 条历史，支持全文检索与收藏夹归类。上个月复制过的那段配置，两秒找回来。

图片与文件

截图从电脑直接落进手机相册，最大 50MB 的文件分块直传。设计稿、压缩包、录屏，跨设备不再需要数据线。

模板与变量

把常用回复、签名、代码片段存成模板，配合变量占位一键插入。客服、开发、运营的重复输入终结者。

离线优先

飞机上、地库里照常复制粘贴。所有操作进入本地队列，恢复联网后按序补同步，一条不丢。

FAQ

你可能想问

端到端加密下，我换新手机怎么办？＋
新设备扫码配对时，密钥通过加密握手安全迁移；旧设备可在「设备管理」中随时下线。你也可以选择不迁移密钥、从全新密钥开始。
免费版和付费版最大的区别？＋
免费版核心同步与加密能力完整可用（2 台设备、50 条历史）。Pro 解锁多设备、大文件、全文搜索与更长版本历史。详见上方定价表。
支持 iOS 吗？＋
iOS 版在规划中。当前支持 Windows / macOS / Linux / Android，同一账号的剪贴板在已支持设备间实时同步。
我的剪贴板历史存在哪里？＋
内容以密文形式存储在服务器用于多设备同步，本机也保留本地副本。历史按套餐上限与过期策略自动清理，删除即彻底删除。
可以退订吗？＋
可以。订阅随时取消，取消当期结束前仍可继续使用；7 天试用期内取消不产生任何费用。
