# ClipSync 官网（Official Website）落地方案

> 版本：v1.0（待人工审核）
> 定位：产品门面 + 下载转化入口；后端要求极低，前端视觉与创意要求极高
> 产出：**三个创意方向的完整设计草图**，供人工比稿

---

## 1. 目标与成功标准

- 让访客 10 秒内理解「手机复制、电脑秒粘」这一核心价值；
- 传达「端到端加密 = 安全可信」的专业感；
- 引导下载（Windows / macOS / Android 优先）与查看定价；
- 视觉上是一眼记住的、有品牌感的产品官网，而非模板站。

## 2. 信息架构（三个版本共用，表达方式不同）

```
① Hero：一句话价值主张 + 主视觉（同步过程的动态演绎）+ 双 CTA（下载 / 查看定价）
② 信任条：E2E 加密 · 开源精神 · 本地优先 · 多平台
③ 核心功能：实时同步 / AI 分类 / 历史与搜索 / 文件传输 / 模板 / 共享链接（配动效演示或静态演示图）
④ 安全章节：AES-256-GCM、服务端不可读、设备密钥配对
⑤ 工作流演示：「手机 → 电脑」三步图 / 场景故事（验证码接力是真实杀手场景）
⑥ 定价：Free / Pro ¥9.9 月（¥99 年）/ Enterprise ¥19.9 月（¥199 年）——与 subscription_plans 表一致
⑦ 下载：多平台按钮 + 系统要求
⑧ FAQ + 页脚（备案占位、文档、联系）
```

**文案事实来源**（保证官网与产品一致）：README 核心功能、`subscription_plans` 种子数据、移动端实际功能页（剪贴板/设备/收藏/模板/共享链接/订阅）。

## 3. 技术选型

- **推荐：纯静态站（单页 HTML/CSS/JS 或 Astro）**——内容少、SEO 友好、零运维；动效用 CSS 原生动画 + 少量 JS（IntersectionObserver 滚动入场）。
- 若后续要博客/更新日志：升級 Astro + Markdown 内容集合，构建产物依旧纯静态。
- 部署：nginx 独立 server 块（`www.clipchain.top`）或 CNB Pages / GitHub Pages；表单类需求（联系/反馈）先 mailto，后接现有 surveys 接口。
- 品牌规范：主色 `#5A4BD1`（浅）/`#C3B6FF`（深）、中性色 zinc 系、展示字体思源黑体/系统栈 + 数据用 JetBrains Mono 气质等宽。

## 4. 三个创意方向（对应三版草图）

### V1「Aurora 夜航」— 深色科技 · 光与流动
- 深空底色 + 品牌紫极光渐变光晕 + 玻璃拟态卡片；
- Hero 中心是一台手机和一台电脑的抽象剪影，一条光带把「验证码」从手机送到电脑（CSS 动画循环），直击核心场景；
- 适合：科技感最强、最"亮眼"，与暗色客户端气质呼应。

### V2「Paper 极简」— 亮色编辑风 · 大字排版
- 近白底、超大号衬线/黑体标题、细分割线、克制的单色强调；
- 用纯排版与编号章节讲述产品（01 同步 / 02 加密 / 03 AI…），配 CSS 搭建的应用窗口示意；
- 适合：高级感、专业感、Long-form 阅读；Linear/Stripe 文档页气质。

### V3「Prism 棱镜」— Bento 活力 · 明快现代
- 明亮浅底 + Bento Grid（不等宽圆角卡片矩阵），每张卡一个小场景动画/微交互；
- 定价卡直接内嵌在 bento 中，下载按钮大而醒目；
- 适合：亲和、活泼、信息密度高，转化导向。

> 三版均为完整单文件 HTML（无外部依赖，双击即开），文案用真实功能与真实价格。

## 5. 与后台系统的关系

- 官网定价页读取口径与 `subscription_plans` 一致；后续可由后台「公告系统」统一维护官网横幅（远期）。
- 下载链接初期指向固定发版地址（GitHub Releases / 国内 CDN），后台 M3 后可接入「版本管理」。
