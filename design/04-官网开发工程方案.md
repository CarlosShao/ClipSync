# ClipSync 官网 — 开发工程方案（待审核）

> 版本：v1.0 · 视觉基线：`design/mockups/website-v2-minimal.html`（Paper 极简，已定稿）
> 定位：产品门面 + 下载转化，纯静态站；后端零依赖
> 审核通过前不开始编码。

---

## 1. 技术选型

| 项 | 选型 | 理由 |
|----|------|------|
| 构建 | Vite 6（多页模式，`rollupOptions.input` 预留多页） | 开发热更 + 产物 hash 指纹；未来可无痛加页 |
| 框架 | **无框架，原生 TS + 模板** | 单页营销站，React 反而是负担；草图已是最终视觉，直接工程化还原 |
| 样式 | 手写 CSS + 设计 token（`styles/tokens.css`）| 草图 CSS 即蓝本，保证 1:1 还原；CSS 自定义属性管色板 |
| 动效 | IntersectionObserver + CSS transition/animation | 草图已验证；不引入 GSAP 等重库 |
| 部署 | nginx `www.clipstream.work`（或 CNB Pages） | 静态产物 `dist/` |

**明确不做**：React/Vue 引入、SSG/Astro（等有博客/更新日志需求再升级，届时内容页用 Astro 迁移，主视觉页保留）。

## 2. 项目结构

```
src/website/
├── package.json            # name: clipsync-website（独立 npm 包）
├── vite.config.ts
├── tsconfig.json
├── index.html              # 主页（草图 V2 全量内容）
├── public/
│   ├── favicon.svg
│   └── og-cover.png        # OG 分享图（从 V2 首屏导出）
└── src/
    ├── main.ts             # 入场动画 / FAQ 折叠 / 导航滚动状态 / 锚点平滑滚动
    ├── styles/
    │   ├── tokens.css      # 色板：--ink #141414 / --accent #5a4bd1 / --line #e6e4dc …
    │   ├── base.css        # reset + 排版
    │   └── sections/       # hero / sync / encrypt / pricing / download / faq / footer 分文件
    └── data/
        └── pricing.ts      # 定价常量（与 subscription_plans 表一致，页脚注明更新日期）
```

## 3. 关键工程要求

1. **还原精度**：以 `website-v2-minimal.html` 为像素基线；分节 CSS 拆文件但类名保持一致，方便对照走查。
2. **响应式断点**：≥1440（max-w 1160 居中）、960–1440、<960（单列、导航折叠为纯 logo+CTA）。与草图 media query 保持一致。
3. **SEO**：`<title>`/`description`/OG/Twitter 卡、`<html lang="zh-CN">`、语义化标签（header/nav/main/section/footer）、价格区块 JSON-LD（Product + Offer）。
4. **性能预算**：无三方 JS；图片仅 og-cover 与可选截图（WebP，≤100KB/张）；Lighthouse Performance/SEO ≥ 95（CI 中用 playwright + lighthouse 跑分）。
5. **可访问性**：FAQ 用原生 `<details>`；对比度 ≥ 4.5:1；键盘可达（跳转链接）。
6. **内容单一来源**：定价/功能清单放 `data/pricing.ts`，官网文案改价只动一处；与后台 `subscription_plans` 的一致性在 M3 后由后台「公告系统」人工核对（写进运维清单）。
7. **下载链接**：统一 `data/download-links.ts` 占位（GitHub Releases / 国内 CDN），上线前替换真实地址。

## 4. Git / 流程

- 与后台同分支 `feature/admin-console` 开发（目录独立，互不阻塞）；提交 `feat(website): …`
- 推送双远端 `origin` + `cnb`；验收后随分支合并 `dev/cnb`
- 上线检查单：域名解析、TLS、ICP 备案占位替换、统计脚本（是否接，待你拍板）、404 页

## 5. 需要你在审核时一并拍板

1. 域名用 `www.clipstream.work` 还是根域 `clipstream.work`（或两者都上，根域 301）
2. 是否接访问统计（自托管 umami / 不接）
3. 下载链接初始指向（GitHub Releases？国内 CDN 哪家？）
