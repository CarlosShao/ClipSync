## 九、桌面端 PIN（可选，2 分钟）—— AF-55（前端 HMR 已生效）

1. 桌面端设置 → 隐私 → 设置 PIN（4-6 位）。
2. F12 或直接查 localStorage（DevTools Application 面板）：`clipsync-privacy-pin` 应为 **64 位 hex 哈希**，另有一个 `clipsync-privacy-pin-salt`；**看不到明文 PIN**。
3. 锁定后用 PIN 解锁 → 正常解锁；清除 PIN 后两个键都消失。
4. 老用户（升级前已设 PIN）：首次启动后明文键被自动替换为哈希，旧 PIN 仍可解锁。
