# 备案与域名合规操作指南（2026-09-09）

> 配套文档：`docs/audit/external-dependency-audit-2026-09-09.md`（A1 域名 / C5 软著 / C6 备案 / B1-B2 支付）
> **本文件修正了 `docs/product/domestic-android-publish-guide.md:43-64` 的不准确表述**（原文档把 ICP 备案与 APP 备案写成"两个独立流程"、周期写短了），**冲突以本文件为准**。

## 0. 结论先行

**不是"同时申请"，是"先后"**：

```
域名实名认证（1-3 天，备案前置）
        ↓
ICP 备案 / 网站备案（10-20 天）→ 拿到主体备案号
        ↓  必须在主体备案通过后
APP 备案（3-10 天）→ 仅上国内应用商店才需要
```

**当前项目（clipchain.top + 阿里云大陆 ECS）实际需要**：

| 资质 | 是否需要 | 说明 |
|---|---|---|
| 域名实名认证 | ✅ 现在办 | 备案前置 |
| **ICP 备案** | ✅ **现在办** | 大陆服务器 + 域名解析必须备案；**微信/支付宝回调域名要求已备案** → 它是支付的前置 |
| APP 备案 | ⏸ **暂不需要** | 仅 Android/iOS 上国内商店才要；**桌面端 exe 走官网下载不算 App，不需要 APP 备案** |
| 软件著作权 | ⚠️ **现在启动** | 国内安卓商店硬门槛，40-60 工作日，全场最慢 |
| ICP 许可证 | ⚠️ 合规层面 | 有订阅收费建议办（经营性），但**商店上架不强制**，可后补 |

## 1. 概念辨析（易混）

| 名词 | 本质 | 谁要求 | 入口 |
|---|---|---|---|
| **域名实名认证** | 域名注册商处实名 | 注册局/注册商 | 阿里云域名控制台 |
| **ICP 备案**（网站/主体备案） | 域名解析到大陆服务器必须备案 | 工信部（管局） | 接入商备案系统 https://beian.aliyun.com |
| **APP 备案** | 移动应用在中国大陆提供服务必须备案（《移动互联网应用程序信息服务管理规定》2023） | 工信部 | 同上，在**已备案主体下新增 APP** |
| **软件著作权** | 著作权登记，证明软件权属 | 各应用商店（非工信部备案前置） | 中国版权保护中心 https://www.ccopyright.com.cn |
| **ICP 许可证** | 增值电信业务经营许可（经营性信息服务） | 省通信管理局 | 各省通管局（企业主体，注册资本多要求 ≥100 万） |

**关系**：APP 备案**依托**于已备案主体 ≠ 与 ICP 备案并列独立。原项目文档"两个独立流程"表述错误。

## 2. ICP 备案（阿里云）操作流程

### 2.1 前置条件（不满足会被卡）

1. **域名已实名认证**：阿里云控制台 → 域名 → 实名认证状态 = "成功"（新注册域名 1-3 天）
2. **服务器有备案资格**：中国大陆 ECS **包年包月 ≥ 3 个月**且有公网 IP；不满足则购买"备案服务码"或续费。轻量应用服务器以套餐为准 → **最终以备案系统实时校验结果为准**（提交时系统会自动判断并给出订单号）
3. **主体材料**
   - 个人：身份证正反面、手机号、通信地址
   - 企业：营业执照、法人身份证、网站负责人身份证（可同一人）

> ⚠️ **主体选择建议**：ClipSync 有订阅收费，**建议企业 / 个体工商户主体**。个人主体不可从事经营性业务，后续 ICP 许可证无法办理，且微信支付商户本就要求企业资质（需营业执照）。

### 2.2 提交步骤

1. 打开 https://beian.aliyun.com → 登录 → **开始备案** → 首次备案
2. **填写主体信息**（个人或企业，按执照/身份证如实填）
3. **填写网站信息**（驳回重灾区，照抄）

| 字段 | 建议值 | 禁忌 |
|---|---|---|
| 网站名称 | `ClipSync 剪贴板同步服务` | 禁含"中国""最强""官网"+公司名；禁含"论坛/支付/网盘/出版"等触发前置审批词 |
| 域名 | `clipchain.top` | **子域（api./ws./updates./www.）无需单独备案** |
| 服务类型 | **「其他」或「互联网信息服务」** | 绝不可选交互式/论坛/出版/支付 |
| 服务内容 | `为桌面端与移动端提供剪贴板同步服务的官方网站与 API 接口` | — |
| 服务器 | 你的 ECS 公网 IP / 备案服务码 | — |

4. **人脸核验**：下载「阿里云」App → 备案 → 扫脸（多数省份已免幕布照片）
5. **阿里云初审**：1-2 个工作日，注意接听 **0571 / 95187** 核对电话
6. **工信部短信核验**：收到 **12381** 短信后 **3 天内**回复验证码（过期作废需重提）
7. **管局审核**：7-20 个工作日（多数 10-15 天）
8. **通过**：获得备案号（如 `浙ICP备2026XXXXXXXX号`），**必须展示在官网底部**

## 3. APP 备案流程（上国内商店时再做）

**两个硬前提**
1. ICP 主体已备案通过
2. Android 已生成 keystore（要提交**签名 MD5 指纹**）→ 因此 C3（Android keystore）必须排在 APP 备案之前

**步骤**
1. https://beian.aliyun.com → 备案 → **新增 APP**（挂在同一主体下）
2. 填写：APP 名称、图标、包名、签名 MD5、服务类型、隐私政策 URL、服务域名/IP
   - Android 包名：`com.clipsync.clipsync_mobile`（`android/app/build.gradle.kts:22`）
   - iOS Bundle ID：`com.clipsync.clipsyncMobile`（`ios/Runner.xcodeproj/project.pbxproj:385`）
   - ⚠️ 两者**当前不一致**，上架前建议统一（同见 `external-dependency-audit` C3/C4）
3. 阿里云初审 → 管局审核 **3-10 个工作日**
4. 取得 APP 备案号（如 `浙ICP备2026XXXXXXXX号-2A`）→ 上架商店填写

**取签名 MD5**
```bash
keytool -list -v -keystore clipsync-keystore.jks -alias clipsync
# 输出中 "MD5:" 行即为所需
```

## 4. clipchain.top 域名规划

备案只需主域名，以下子域在备案通过后按需解析：

| 子域 | 用途 | 对应代码位置 |
|---|---|---|
| `api.clipchain.top` | 后端 API（含支付回调） | `k8s/base/ingress.yaml:20`；`docs/product/payment-integration-guide.md:73,139,190` |
| `ws.clipchain.top` | WebSocket | `k8s/base/ingress-networkpolicy.yaml:48` |
| `updates.clipchain.top` | Tauri 更新端点 | `src/desktop/src-tauri/tauri.conf.json:53` |
| `www.clipchain.top` | 官网 | `src/website/public/sitemap.xml:7` |

> ⚠️ 仓库内现有 4 套不一致域名（clipsync.com / clipsync.app / clipstream.work / updates.clipsync.app），**必须统一为 clipchain.top**（见 `external-dependency-audit` 第 1 节问题 2）。

**备案期间如何联调**：未备案域名解析到大陆 80/443 会被拦截 → 用 **服务器 IP + 3001 端口直连**做开发与接口测试，不受影响。

## 5. 时间线

| 时间 | 动作 |
|---|---|
| 今天 | ① 查 clipchain.top 实名状态 ② 确认 ECS 备案资格 ③ **提交 ICP 备案** ④ **提交软著申请**（最慢，必须现在启动） |
| 备案期间 10-20 天 | IP 直连联调；准备隐私政策、权限说明、商店素材 |
| 备案通过 | DNS 解析 → Let's Encrypt → HTTPS → 接微信/支付宝（此时域名已备案，满足要求） |
| 上安卓商店前 | 生成 keystore → 取签名 MD5 → APP 备案（3-10 天）→ 上架（软著 + APP 备案 + 隐私政策） |

## 6. 高频驳回原因（逐条避开）

1. **网站名称不合规**（最高频）——按 §2.2 表格填
2. **服务类型选错**触发前置审批
3. **12381 短信未在 3 天内核验**
4. 备案手机号接不到审核电话
5. 域名实名认证未完成就提交
6. 本人/手机号已在其他主体备过案 → 应走"新增网站"而非"首次备案"
7. 服务器不满足时长/规格要求（系统校验不通过）

**备案后义务**：备案号展示在网站底部；主体/服务器/域名变更需做"变更备案"；每年配合年度真实性核验（短信）。
