## 1. 软件概述

ClipSync 是一款跨设备剪贴板同步软件，核心解决「手机复制、电脑粘贴（反之亦然）」的多端协作痛点。软件由**后端同步服务（Node.js + Express + WebSocket）**、**桌面客户端（Tauri 2 / Rust + WebView，支持 Windows / macOS）**、**移动客户端（Flutter，支持 Android / iOS）** 三部分组成，通过端到端加密在设备间安全同步剪贴板内容。

## 2. 运行环境

- **服务端**：Node.js 22.x，PostgreSQL 15，Redis 7（可用 Docker Compose 一键编排）
- **桌面端**：Windows 10 及以上 / macOS 12 及以上
- **移动端**：Android 8.0 及以上 / iOS 14 及以上
- **网络**：客户端与服务端通过 HTTPS / WSS 通信，剪贴板数据端到端加密传输

## 3. 安装与启动

### 3.1 后端同步服务

```bash
cd src/server
npm install
npm run dev
```

服务启动后默认监听 `http://localhost:3000`，提供 `/api` 接口与 `/ws` 实时同步通道。

### 3.2 桌面客户端

```bash
cd src/desktop
npm install
cargo tauri dev
```

桌面窗口打开后即进入主界面，首次使用需通过手机号验证码登录并绑定本机设备。

### 3.3 移动客户端

```bash
cd src/mobile
flutter pub get
flutter run
```

在模拟器或真机上运行后，同样通过验证码登录并自动注册当前设备。

## 4. 主要功能与操作方法

### 4.1 用户注册与登录

[图 1：登录界面]

软件采用手机号 + 验证码登录。打开任一客户端，输入手机号 → 获取验证码 → 输入验证码即完成注册并登录，无需设置密码。登录态以 Token 形式保存在本地安全存储中。

### 4.2 设备管理与绑定

[图 2：设备列表界面]

登录后自动将当前设备注册到账号下。在「设备管理」页可查看已绑定设备（名称、类型、在线状态、最近活跃时间），支持：

- 设备重命名（便于区分「我的笔记本」「我的手机」）
- 设备删除（移除后该设备不再接收同步）
- 在线状态实时显示

### 4.3 实时剪贴板同步

[图 3：剪贴板主界面]

这是软件的核心功能。在任一已登录设备的任意应用内复制文本/图片/文件，服务端通过 WebSocket 实时推送到同账号下的其他在线设备；目标设备剪贴板自动更新，实现「手机复制 → 电脑粘贴」。

- 复制即上传、自动同步，无需手动操作
- 离线时本地缓存，联网后自动补传
- 支持文本、链接、验证码、代码片段、图片、文件多种类型

### 4.4 历史记录与搜索

[图 4：历史记录界面]

所有同步过的剪贴板内容按时间倒序保存在「历史」列表，支持：

- 关键词搜索（按内容模糊匹配）
- 收藏（置顶常用条目）
- 自动过期（可配置保留时长，到期自动清理）
- 单条删除 / 批量清理

### 4.5 AI 智能分类

[图 5：AI 分类与思考面板]

软件内置 AI 模块，可自动识别剪贴板内容类型并给出智能处理：

- 自动识别「验证码 / 链接 / 代码 / 图片 / 文件」并打标签
- 对长文本可调用 AI 进行摘要、翻译、改写
- 支持接入用户自带的多种大模型供应商 Key（密钥加密存储于服务端）

### 4.6 文件与图片同步

[图 6：文件传输界面]

除文本外，软件支持图片与文件在设备间同步，单文件最大 50MB：

- 拖拽或选择文件上传
- 服务端存储并推送元数据，接收端可预览 / 下载
- 大文件采用分片与去重（按字节哈希），减少重复传输

### 4.7 端到端加密

隐私数据在客户端完成 AES-256-GCM 加密后再上传，服务端仅存储密文，无法读取明文，保障跨设备传输的隐私安全。

### 4.8 主题与外观

支持浅色 / 深色 / 跟随系统三档模式，并提供多套界面主题，用户可在设置中切换。

### 4.9 管理后台

[图 7：管理后台界面]

服务端提供 Web 管理后台，供运营者使用：

- 基于角色的权限控制（RBAC：超级管理员 / 管理员 / 普通用户）
- 系统设置（邮件 SMTP、存储、AI 供应商等配置）
- 订单与支付对账
- 设备与用户统计

## 5. 典型使用流程

1. 在服务端部署 `src/server` 并启动（详见第 3.1 节）。
2. 在桌面端与移动端分别安装并启动客户端（第 3.2 / 3.3 节）。
3. 两端使用同一手机号登录，系统自动注册并绑定设备。
4. 在手机上复制一段文本，电脑端剪贴板立即更新，直接 `Ctrl/⌘ + V` 粘贴。
5. 在「历史」中收藏常用条目、搜索过往内容。
6. 运营者在管理后台查看统计、配置系统参数与处理订单。

---

## 6. 注意事项

- 登录验证码通过短信 / 邮件下发，请保管好账号手机号。
- 开启端到端加密后，若丢失本地密钥将无法解密历史内容，请妥善备份。
- 单文件同步上限 50MB，超大文件建议使用专业网盘工具。
- 管理后台账号权限分级，请勿将管理员凭证泄露给非授权人员。
