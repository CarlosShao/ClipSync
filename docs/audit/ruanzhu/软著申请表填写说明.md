# 软件著作权申请表 填写说明（ClipSync）

> 软著申请表在中国版权保护中心官网在线填写（https://www.ccopyright.com.cn）。
> 本文件给出各字段的建议值，照抄即可，带「★」的按实际情况填。

---

## 一、软件基本信息

| 字段 | 建议填写 | 说明 |
|------|----------|------|
| 软件全称 | `ClipSync 剪贴板同步软件` | 含"软件/系统"字样更易过；不要带"中国/最强/官网"等词 |
| 软件简称 | `ClipSync` | 可留空，但建议填，便于检索 |
| 版本号 | `V1.0.0` | 与代码、`tauri.conf.json` 版本一致 |
| 软件分类 | `应用软件` → `其他应用软件`（或`实用工具`） | |
| 行业领域 | `其他` / `信息技术` | |

## 二、开发与发表信息

| 字段 | 建议填写 | 说明 |
|------|----------|------|
| 开发完成日期 | ★ 实际完成日（如 `2026-08-30`） | 不晚于申请日即可 |
| 发表状态 | **未发表** | 当前 App / 官网尚未公测上线，选"未发表"最稳妥，避免填发表 URL |
| 发表日期 / 地点 | 留空 | 选"未发表"后不填 |
| 权利取得方式 | `原始取得` | 自己开发的选这个 |
| 权利范围 | `全部权利` | |
| 开发方式 | `独立开发` | 个人独立开发 |

## 三、著作权人（申请人）

| 字段 | 填写 |
|------|------|
| 著作权人类型 | `自然人`（个人） |
| 姓名 | ★ 你的姓名（与身份证一致） |
| 证件类型 | `身份证` |
| 证件号码 | ★ 身份证号 |
| 国籍 / 地址 | ★ 按身份证填 |
| 联系电话 / 邮箱 | ★ 你的常用联系方式 |

> ⚠️ 若后续你注册了**个体工商户**并希望软著归个体户所有，此处改填「企业法人」+ 营业执照信息即可；个人软著同样可用于上架，只是商店账号主体需与软著权利人一致或附授权书。

## 五、提交的源程序与文档

- **源程序**：提交后端 Node.js 源程序「前 30 页 + 后 30 页」，每页 50 行（见 `源代码_前30页.txt` / `源代码_后30页.txt`）。若程序不足 60 页则提交全部（见 `源代码_全部.txt`）。
- **文档**：提交本目录 `操作说明书.md`（打印为 PDF 提交）。
