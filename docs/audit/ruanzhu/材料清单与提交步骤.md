## 二、在线提交步骤（中国版权保护中心）

1. 注册 / 登录：https://www.ccopyright.com.cn（个人用身份证注册账号）
2. 进入「版权登记」→「软件登记」→「新建申请」
3. 按 `软著申请表填写说明.md` 逐字段填写（软件全称、版本、著作权人=自然人等）
4. 上传附件：
   - 源程序文档（txt / pdf，前30+后30页）
   - 操作说明书（PDF）
   - 身份证扫描件
5. 确认提交 → 等待**受理通知书**（一般 1–3 个工作日出受理号）
6. 审查周期：**普通 40–60 工作日**；加急 5–15 工作日（需额外费用，看官网当期政策）
7. 通过后下发《计算机软件著作权登记证书》（电子证书，官网可下载）

## 三、关于「个人没有公司」的补充说明（重要）

你目前是**纯个人开发者**，这不影响软著本身——个人完全可以申请软著，提交身份证即可。

但个人身份会在后续两步卡住，建议提前规划：

### 卡点 1：付费订阅（微信支付 / 支付宝）
- 微信支付商户号、支付宝企业账号**必须营业执照**（个体工商户即可，不是公司）。
- 解决：去注册**个体工商户**（多数省份政务服务网全程网办，免费或几元，1–3 天）。
- 有了执照即可开通支付，软著权利人可保持个人（商店/支付不强制与软著权利人一致）。

### 卡点 2：国内安卓商店上架
- 华为 / 小米 / OPPO / vivo 开发者账号基本要求企业主体；应用宝 / 360 支持个人但受限。
- APP 备案依托"已备案主体"，个人主体也能做，但商店审核通常更顺的是企业。
- 解决：同样用**个体工商户**营业执照开开发者账号，软著 + APP 备案 + 隐私政策齐备即可上架。

## 五、当前已注册个人账号，怎么办？推荐方案 A（最省时间）

**方案 A（推荐）：个人软著 + 个体工商户执照并行**
1. 软著继续用**已注册的个人账号**提交，著作权人=你本人。
2. 同时去注册**个体工商户**（1–3 天）。
3. 微信支付/支付宝商户号用**个体户营业执照**开通。
4. 国内安卓商店开发者账号用**个体户**注册；上架时附《软著授权书》（见本目录 `软著授权书_个人授权个体户模板.md`），把个人软著授权给个体户使用。
5. ICP 备案：
   - 若还在腾讯云初审阶段，可尝试**撤回重提**为个体户主体；
   - 若已进入管局审核，先让个人主体通过，拿到执照后再做**变更备案**到个体户。
6. APP 备案：必须挂在已通过 ICP 备案的主体下；建议等主体变更为个体户后再做。

> **为什么不重新注册软著机构账号？** 软著账号类型改不了，重新注册机构账号需要新手机号/邮箱，且要等执照下来才能提交，会把 40–60 天的软著周期往后拖。个人软著 + 授权书是行业常规操作，商店普遍接受。

**方案 B（主体完全对齐，但最慢）**
- 拿到执照后重新注册中国版权保护中心「机构」账号，以个体户名义申请软著。
- 优点：权利人和运营主体一致，无需授权书；
- 缺点：软著提交会被执照办理耽误，且需要新账号。

**方案 C（纯个人路线）**
- 只做桌面端 exe 官网分发 + 海外（Google Play / F-Droid），不做国内安卓商店和微信/支付宝应用内付费。
- 无需执照，但商业化天花板低。
