## §5 踩过的坑（务必避免重复）

1. **`vue-tsc --noEmit` 不检查模板标签配对** ⇒ 改 `.vue` 模板后必须**让 dev server 真编译一次**
   （`curl -o NUL -w "%{http_code}" http://localhost:1420/src/components/auth/AuthPage.vue`，200 才算过）
   或跑 `vite build`。我因为只看 tsc，两次把桌面端登录页改成红屏（`Invalid end tag.`）。
2. **不要用行拼接脚本改大文件** ✗ —— 我一次匹配错"结束行"，删掉设置页 342 行（已 `git checkout` 恢复）。
   只用"先读区间 → 编辑器精确替换"，且替换块要**把闭合标签一起包含**（我漏了 `</div>` 才导致红屏）。
3. **PowerShell 陷阱**：`cd` 对 .NET 的相对路径无效（用绝对路径）；`$()` 在双引号里会解析（用单引号）；
   `git commit -m` 里有引号会被 shell 拆开 ⇒ **一律写消息文件 `git commit -F`**；`Select-String -SimpleMatch`
   下 `(` 是字面量，别用它判断"函数被调用次数"。
4. **生产 backport 的幂等守卫必须精确**：我两次用过通用的守卫串（如 `turnstile_secret_key`），
   导致"落库加密清单"被误判 ALREADY 而静默跳过（会让 secret 明文落库）。改完必须**跑断言 + 功能实测**。
5. **SSH 到生产偶尔瞬时断连**（`Connection closed by remote host`）⇒ 重试即可，不要据此下结论。
6. 生产 `psql` 走 heredoc 会被引号吃掉 ⇒ **写 .sql 文件 scp + `docker cp` + `psql -f`**。
