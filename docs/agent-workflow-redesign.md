# ClipSync Agent 工作流输出改造建议

## 一、当前问题诊断

### 1.1 视觉层面问题
| 问题 | 现状 | 影响 |
|------|------|------|
| 使用 Emoji | 💡🤖🔧 等图标 | 不够专业，跨系统显示不一致 |
| 节点图标过大 | 22px 圆形 + 边框 | 视觉抢眼，干扰内容阅读 |
| 时间线过于突出 | 2px 粗线 + 实色 | 喧宾夺主 |
| 协调器概念暴露 | 显示"协调器 DONE" | 用户无法理解内部概念 |

### 1.2 信息架构问题
| 问题 | 现状 | 影响 |
|------|------|------|
| 缺少阶段划分 | 思考/工具/代理平铺 | 用户无法感知工作流进度 |
| 协调器暴露 | 显示"协调器"卡片 | 用户困惑这是什么 |
| 子代理无目标 | 只显示名称 | 用户不知道它在做什么 |
| 无完成状态 | 只有 done/failed | 缺少"进行中"的明确反馈 |

### 1.3 交互层面问题
| 问题 | 现状 | 影响 |
|------|------|------|
| 折叠逻辑混乱 | 历史消息折叠，最新展开 | 用户可能错过重要信息 |
| 流式状态不清 | 思考中/完成状态切换不明显 | 用户不知道AI是否在工作 |

## 二、TraeWork 标准 Agent 工作流分析

### 2.1 TraeWork 的输出结构
```
┌─────────────────────────────────────────────────────┐
│ [AI Logo] 思考过程 1s                     [展开/折叠] │
├─────────────────────────────────────────────────────┤
│ 用户提问：xxx                                        │
│ AI 分析：xxx（思考内容）                              │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ [✓] 任务规划                                         │
│ ├─ 子任务1: 描述                                     │
│ └─ 子任务2: 描述                                     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ [执行中] 子代理执行                                   │
│ ├─ ○ 子代理1: 名称 ────────────────── [done]       │
│ └─ ○ 子代理2: 名称 ────────────────── [working]    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ [输出]                                               │
│ 最终的回答内容...                                     │
└─────────────────────────────────────────────────────┘
```

### 2.2 TraeWork 的设计原则
1. **无 Emoji** - 全部使用 SVG 图标
2. **阶段清晰** - 思考 → 规划 → 执行 → 输出
3. **协调器隐藏** - 用户不感知"协调器"概念
4. **子代理有目标** - 每个子代理显示具体任务
5. **时间线简洁** - 细线 + 小圆点，不抢内容

## 三、改造方案设计

### 3.1 工作流阶段定义

```typescript
// 工作流阶段枚举
enum WorkflowPhase {
  THINKING = 'thinking',      // 思考分析
  PLANNING = 'planning',      // 任务规划
  EXECUTING = 'executing',    // 执行中
  OUTPUT = 'output',          // 输出结果
}

// 阶段状态
enum PhaseStatus {
  PENDING = 'pending',        // 等待中
  ACTIVE = 'active',          // 进行中
  COMPLETED = 'completed',    // 已完成
  FAILED = 'failed',          // 失败
}
```

### 3.2 时间线节点设计

```
节点类型：
1. 思考节点 [Brain图标] - 可折叠，显示思考时长
2. 规划节点 [ListChecks图标] - 显示子任务列表
3. 工具节点 [Wrench图标] - 紧凑，显示工具名
4. 子代理节点 [Bot图标] - 显示名称+状态+目标
5. 输出节点 [无图标] - 主要内容，Markdown渲染
```

### 3.3 图标规范

| 阶段 | 图标 | 来源 | 颜色 |
|------|------|------|------|
| 思考 | Brain | lucide-vue-next | brand blue |
| 规划 | ListChecks | lucide-vue-next | brand blue |
| 工具 | Wrench | lucide-vue-next | neutral |
| 子代理 | Bot | lucide-vue-next | 按状态 |
| 成功 | CheckCircle2 | lucide-vue-next | success green |
| 失败 | XCircle | lucide-vue-next | error red |
| 进行中 | Loader2 | lucide-vue-next | brand blue (旋转) |

### 3.4 时间线样式规范


## 四、子代理展示优化

### 4.1 当前问题
- 只显示名称，无任务目标
- 状态只有 done/failed，缺少 working/planning
- 没有展示工具调用历史

### 4.2 建议展示结构

```
┌─────────────────────────────────────────────────────┐
│ [Bot图标] 子代理名称                                 │
│ ─────────────────────────────────────────────────── │
│ 目标: 完成xxx数据的查询和统计                         │
│ 工具: get_favorites, get_statistics                  │
│ 状态: [done] 3s                                     │
└─────────────────────────────────────────────────────┘
```

### 4.3 数据结构调整

```typescript
interface AgentRun {
  id: string
  name: string
  objective: string      // 新增：任务目标
  tools: string[]        // 新增：使用的工具列表
  status: AgentRunStatus
  duration?: number      // 新增：执行耗时
  error?: string
}
```

## 五、协调器概念隐藏方案

### 5.1 当前问题
- "协调器 DONE" 对用户是黑盒
- 用户不知道这是什么

### 5.2 解决方案
1. **不显示协调器节点** - 协调器是内部概念
2. **用"任务规划"替代** - 如果协调器生成了子代理计划，显示为"任务规划"节点
3. **合并到思考中** - 协调器的分析过程合并到思考过程中

```typescript
// 后端修改：协调器事件不下发到前端
const wrappedSend = (obj) => {
  const d = obj?.choices?.[0]?.delta
  // 过滤掉协调器事件
  if (d?.agent?.kind === 'coordinator') return
  sendDelta(obj)
}
```

## 六、流式输出优化

### 6.1 当前问题
- 思考中状态不明显
- 流结束时无明确反馈

### 6.2 优化方案

1. **思考中**：图标旋转脉冲 + 蓝色边框
2. **思考完成**：图标变为静态蓝色 + 显示耗时
3. **流式输出中**：内容末尾显示闪烁光标
4. **全部完成**：自动折叠思考过程，展示最终结果
