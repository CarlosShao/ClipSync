## 产品定位与 B2B 功能说明

### 产品定位
**ClipSync = 个人跨设备剪贴板同步工具**

- **核心场景**：个人用户在不同设备间同步剪贴板内容
- **目标用户**：程序员、设计师、办公人员等需要跨设备工作的个人
- **不是**：团队协作工具、企业知识库、代码片段管理平台

### 核心竞争力（与竞品的差异化）

ClipSync 的核心差异化应该是以下 4 点，所有开发工作围绕这 4 个方向展开：

| # | 核心优势 | 说明 | 竞品对比 |
|---|----------|------|----------|
| **1** | **同步速度（比 AirDrop 更方便）** | 实时推送，毫秒级延迟，无需手动操作 | AirDrop 需要手动选择文件/接收；ClipSync 自动同步 |
| **2** | **跨平台（Windows + macOS + Android + iOS）** | 全平台覆盖，不受操作系统限制 | Universal Clipboard 仅限 Apple 设备；Paste 仅 macOS |
| **3** | **隐私安全（端到端加密）** | ECDH 密钥交换，服务器无法查看明文内容 | 多数竞品无端到端加密；数据明文存储 |
| **4** | **离线支持（无网络时也能用）** | 本地缓存队列，网络恢复后自动同步 | 多数竞品离线即失效 |

> **开发原则**：每个新功能开发前，先回答——这个功能是否强化了上述 4 个核心优势？如果不是，降低优先级。

### 为什么 B2B 功能不是核心需求

**问题**：剪贴板工具需要 B2B 功能吗？

**答案**：❌ **不需要**。原因：

1. **剪贴板内容是个人隐私数据**
   - 用户复制的密码、信用卡号、私人消息不应该共享
   - 团队共享剪贴板有严重的安全和隐私风险

2. **B2B场景有更专业的工具**
   | B2B场景 | 专业工具 |
   |---------|----------|
   | 团队共享代码片段 | GitHub Gist, Notion, Slack |
   | 团队共享密码 | 1Password, Bitwarden 企业版 |
   | 团队共享文本/链接 | Slack, Microsoft Teams |
   | 团队协作 | Notion, Confluence, Figma |

3. **竞品证明**
   - 成功的剪贴板工具（Paste、Copied、Universal Clipboard）**全部是纯个人工具**
   - 没有一家做 B2B，也活得很滋润

4. **用户需求验证**
   - 如果你问用户："你需要团队共享剪贴板吗？"
   - 90% 的用户会说："不需要，这是我的私人数据"

**结论**：B2B 功能应该作为 **v2.0 扩展功能**（可选），而不是 launch  blockers。

## 优先级说明

### P0（必须有）- Launch 前提
| 模块 | 任务数 | 原因 |
|------|--------|------|
| 桌面端增强（Windows） | 14 | **核心竞争力**：没有系统托盘+全局快捷键+剪贴板监控，就不是真正的剪贴板工具 |
| 桌面端适配（macOS） | 8 | **核心竞争力**：macOS 是目标用户（程序员、设计师）主要平台 |
| 移动端适配（iOS） | 10 | **核心竞争力**：iOS API 限制多，需特殊适配策略 |
| 同步性能优化 | 6 | **核心竞争力 #1**：比 AirDrop 更方便，实时推送+增量同步 |
| 账户与GDPR | 16 | **法律要求**：无法在EU运营，会被罚款（GDPR 罚款可达年收入4%） |
| 支付与订阅 | 18 | **商业化前提**：无法收费，项目无法持续 |
| 部署运维（剩余） | 6 | **上线前提**：无法部署到生产环境 |

**P0 小计**：143 项任务（阶段一至阶段十）

| 高级剪贴板功能 | 22 | 模板、Markdown预览、代码高亮（与竞品差异化） |

## 进度追踪规则

### 状态定义
- ✅ **已完成**：任务完成，测试通过，代码已合并
- 🔄 **进行中**：任务正在执行，有具体进展
- ⏳ **待开始**：任务已规划，等待执行
- ❌ **已取消**：任务不再需要
- 🚫 **阻塞**：任务被外部依赖项阻塞

### 完成标准
每个任务必须满足：
1. **功能完成**：代码实现完成
2. **测试通过**：单元测试/集成测试通过
3. **文档更新**：相关文档已更新

## 质量标准

### 代码质量
- **测试覆盖率**：> 80%
- **代码重复率**：< 5%
- **圈复杂度**：< 10

### 性能标准
- **API响应时间**：P95 < 200ms
- **WebSocket延迟**：< 100ms
- **并发用户**：支持1000+

### 安全标准
- **OWASP Top 10**：无高危漏洞
- **数据加密**：传输 + 存储
- **访问控制**：最小权限原则
