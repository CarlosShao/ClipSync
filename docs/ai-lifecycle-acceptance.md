## #228 快捷指令按钮（总结/翻译/格式化/解释）· commit da379bc

### ① 操作路径
1. 打开 AI 面板（Ctrl+J / 右下角 AI 悬浮球）。
2. 看输入框**上方**——应有一行 4 个小按钮：总结 / 翻译 / 格式化 / 解释。
3. 点「总结」→ 输入框自动填入总结 prompt 并立即发送。

### ② 易出 bug 的薄弱点
- 按钮只在「已配置供应商 && 非流式」时可点；没有供应商时应禁用（半透明、不可点）。
- 若输入框已有文字，点击按钮应在末尾**追加** prompt 而不是覆盖。
- 流式回答进行中按钮应禁用，避免重复发送。

### ③ 预期效果
- 输入框上方出现 4 个带图标的小按钮（ListChecks/Languages/AlignLeft/HelpCircle）。
- 点击任一按钮：输入框填入对应中文/英文 prompt（跟语言设置）并立即发送，AI 开始回答。
- 切换英文后按钮文字变成 Summarize/Translate/Format/Explain。

## #229 上下文感知：注入当前页面/收藏夹状态 · commit 5427901

### ① 操作路径
1. 切到「收藏夹」页面（左侧导航）。
2. 打开 AI 面板，发消息例如「我现在在看什么页面？」。
3. AI 回答应能说出你在收藏夹页。

### ② 易出 bug 的薄弱点
- 注入的上下文是**不可见标记**包裹在 user 消息里（␄VIEWCTX␄…␄/VIEWCTX␄），UI 上用户消息**不能显示**这段文字。
- 注入走 user 消息而非 system（后端会覆盖 system，契约约束）。
- 切页后立即发消息，AI 应感知新页面而非旧页面。

### ③ 预期效果
- 在收藏夹页问「我在哪个页面」，AI 答「收藏夹」；在剪贴板页问则答「剪贴板历史」。
- 历史对话里 user 消息气泡干净，看不到任何注入标记。

## #230 主动建议系统（收藏/分类/清理）· commit f2bdce5

### ① 操作路径
1. 打开「剪贴板」列表，勾选**一条文本条目**（复选框）。
2. 顶部筛选栏出现「✨ AI 建议」按钮（带勾选数量角标），点击它。
3. 右下角弹出「AI 建议」浮动卡片，自动开始分析。

### ② 易出 bug 的薄弱点
- 没选中任何文本条目时点击 → 报错提示「请先选中一条文本内容」，不弹卡。
- 分析中显示「AI 正在分析内容…」+ 转圈；供应商没配置时提示去设置。
- 收藏/归档/清理按钮应执行真实动作：收藏→星标点亮；清理→弹**删除确认框**（复用原删除流程，保护敏感条目）；归档→条目移入归档。

### ③ 预期效果
- 建议卡显示：是否值得收藏（♥ 建议收藏/不值得收藏 + 一句话理由）、建议动作（保留/归档/清理 + 理由）。
- 点「收藏」→ 条目星标点亮、卡片关闭、toast「已收藏」。
- 点「清理」→ 弹删除确认框，确认后删除。

## #231 聊天历史关键词搜索 · commit 6db3644

### ① 操作路径
1. 打开 AI 面板，点顶部「历史」按钮（时钟图标）→ 弹出历史会话列表。
2. 列表**顶部有搜索框**，输入关键词（如 "clipboard"）。
3. 命中列表出现：显示对话标题 + 「第 X/Y 条」+ 带高亮的片段。
4. 点击某个命中 → 打开该对话并**滚动定位到那条消息**（目标消息闪烁高亮 2 秒）。

### ② 易出 bug 的薄弱点
- 输入防抖 350ms；清空搜索框应恢复普通列表。
- 命中片段里关键词用 `<mark>` 高亮（accent 色加粗）。
- 点击命中：先切对话（select），再定位滚动（150ms 后 scrollToPos）；定位不到文本时退化为按位置估算。
- 无匹配时显示「没有找到匹配的消息」。

### ③ 预期效果
- 搜 "clipboard" → 多条命中，每条带标题/位置/高亮片段。
- 点命中 → 打开对应对话，自动滚到那条消息并闪烁高亮。
- 清空搜索 → 回到历史会话列表。

## #232 流式输出打字机逐字动画 · commit c35dcd7

### ① 操作路径
1. AI 面板发一条会让模型写较长回答的问题。
2. 观察回答：应**逐字呈现**（约 55 字/秒），末尾有闪烁的光标「▍」。
3. 回答结束后：全文保留、光标消失。

### ② 易出 bug 的薄弱点
- 打字机只对**最后一条流式 assistant 消息**生效；历史消息直接全文显示（无动画）。
- markdown 不能因为逐字截断而渲染错乱（应尽量在段落边界断）。
- 流结束（正常/异常/停止）必须立即显示全文并清定时器，不能卡在半截。

### ③ 预期效果
- 回答逐字打出，节奏接近阅读速度，末尾光标闪烁。
- 流结束后全文完整、无截断、无残留光标。
- 打开旧历史对话：消息直接全文显示，无打字机。

## #235 智能标签自动打标/推荐 · commit 27e1c62

### ① 操作路径
1. 选中文本条目 → 「AI 建议」。
2. 建议卡出现「推荐标签」区块（#tag1 #tag2 …）+ 「应用」按钮。
3. 点「应用」→ 条目被打上这些标签。

### ② 易出 bug 的薄弱点
- 标签 2-5 个、简洁中文（如 工作/代码/网址/密码）。
- 应用后：条目 metadata.tags 持久化到 DB；再次打开建议卡应看到标签已生效（去「剪贴板」筛选栏用标签筛选可验证）。
- 无标签建议（如 AI 未返回）时不显示该区块。

### ③ 预期效果
- 建议卡出现 2-5 个 `#标签` chips + 应用按钮。
- 点应用 → toast「已应用 N 个标签」；切到剪贴板列表用标签筛选能筛出该条目。

## #236 重复内容语义检测与提示 · commit b476c1a

### ① 操作路径
1. 先复制一条长文本（如一段介绍文字），成为历史条目。
2. 再复制一段**同义改写**的文本（意思一样、文字不同），选中它 → 「AI 建议」。
3. 建议卡出现黄色「发现 N 条可能重复的条目」警示，列出原因 + 高/中程度。

### ② 易出 bug 的薄弱点
- 只比对最近 10 条文本候选（排除当前条）；无候选时不显示该区块。
- 检测在建议卡打开时**并行**执行（有「正在检测重复内容…」转圈态）。
- 检测失败不阻塞收藏/标签建议。
- 高度重复（degree=high）与部分重叠（medium）用不同颜色区分。

### ③ 预期效果
- 复制原文再复制改写版 → 建议卡提示「发现 1 条可能重复的条目」，reason 说明语义重复。
- 复制完全无关内容 → 无重复提示。

## #237 工作流规则引擎「当…时自动…」· 后端 596c795 / 前端待提交

### ① 操作路径
1. 打开设置（左下角 Settings）→「AI」分类 → 下方出现「自动规则（工作流）」区块。
2. 点「新建规则」：名称「代码自动收藏」、内容类型「代码」、关键词 `python`、动作「自动收藏」→ 保存。
3. 复制一段含 `python` 的代码 → 剪贴板列表里该条目应**自动点亮星标**（收藏）。

### ② 易出 bug 的薄弱点
- 规则匹配：关键词为**全部命中**（AND）；正则模式用 RegExp 匹配（大小写不敏感）。
- 类型过滤：规则限定类型（如 code）只对该类型生效；`text` 类型匹配所有类型（特殊语义）。
- 命中后按 priority 降序**只执行第一条**，避免多条规则反复改。
- 执行是异步的：创建条目后 1-2 秒内动作生效（可刷新列表查看）。
- 动作：favorite 点亮星标；archive 移入归档；tag 打标签；move_to_collection 移入指定收藏夹（不存在自动创建）。
- 前端表单：关键词/标签用逗号分隔输入；保存校验名称与关键词非空。

### ③ 预期效果
- 新建「python 代码→自动收藏」规则后，复制含 python 代码 → 该条目自动收藏（星标亮）。
- 新建「含『待办』→打 todo 标签」规则后，复制含"待办"文本 → 该条目 metadata.tags 出现 todo（用标签筛选验证）。
- 规则列表可启停（开关）、编辑、删除；停用后复制不再触发。
- 设置页语言切换后整块 UI 跟随中/英文。
