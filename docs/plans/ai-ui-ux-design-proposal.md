## 一、设计哲学与视觉语言

### 1.1 核心设计理念
* **“安静而精准”（Quiet Precision）**：AI 不是喧宾夺主的聊天机器人，而是专注的高性能生产力副驾驶。平时保持极低视觉干扰，工作时以清晰的时序和结构化卡片展示透明进度。
* **“渐进式披露”（Progressive Disclosure）**：三层信息架构——默认呈现核心结论；折叠呈现结构化工作流芯片；点击展开完整的终端级执行与思考细节。
* **“原生桌面级触感”（Desktop Native Tactility）**：采用亚克力/毛玻璃材质（Frosted Glass）、细腻的 1px 微边框、平滑的贝塞尔缓动曲线与 Tabular 数字等宽排印。

### 1.2 配色与材质设计系统
| Token 类别 | 浅色模式（Light Mode） | 深色模式（Dark Mode） | 用途 |
| :--- | :--- | :--- | :--- |
| **Surface Base** | `#FFFFFF` | `#121316` | 侧边栏/主对话画布底色 |
| **Surface Elev-1** | `#F8F9FA` | `#1A1C20` | 输入框/工具卡片底色 |
| **Surface Elev-2** | `#F1F3F5` | `#22252A` | 悬浮菜单/气泡高亮背景 |
| **Border Subtle** | `rgba(0, 0, 0, 0.06)` | `rgba(255, 255, 255, 0.08)` | 1px 细分割线 |
| **Accent Primary** | `#3B82F6` (Electric Blue) | `#60A5FA` | 主交互/高亮色 |
| **Thinking Tint** | `#8B5CF6` (Iris Violet) | `#A78BFA` | 思考状态/推理标签专属色 |
| **Warning / Danger**| `#EF4444` (Coral Red) | `#F87171` | 破坏性权限拦截/删除操作 |
| **Success Tint** | `#10B981` (Emerald) | `#34D399` | 工具执行完成/写入成功 |

## 二、AI 面板整体布局架构升级

```
+-----------------------------------------------------------------------------------------+
| [ClipSync AI Shell]                                                   [Mini] [Full] [X] |
+------------------+-------------------------------------------------+--------------------+
| 🧭 导航与历史     | 💬 动态对话主画布 (Main Canvas)                   | 🔍 上下文与检查器   |
| (Nav Rail)       |                                                 | (Inspector Drawer) |
|                  | [顶部状态条: 会话标题 · 模型选择器 · 权限模式]      |                    |
| + 新建对话       | ----------------------------------------------- | 📊 上下文仪表盘    |
| 📂 项目收藏夹    | [用户消息气泡]                                   |    Tokens: 12k/128k|
| 📜 最近会话      |                                                 |    Cache: 84% 命中 |
| 🏷️ 预设 Agent    | [Agent 复合回复卡片]                             |                    |
| ⚙️ 供应商偏好    |   ├─ 💡 深度思考 (3.2s)                         | 🧠 当前注入记忆    |
|                  |   ├─ ⚡ 工具执行流 (3 步)                       |    - 偏好: 简洁输出|
|                  |   │   └─ [Get] -> [Write] -> [Verify]           |    - 收藏夹: test1 |
|                  |   └─ 📝 最终排版回答                            |                    |
|                  |                                                 | 🛠️ 可用工具清单    |
|                  | ----------------------------------------------- |    12 sensitive    |
|                  | [浮动智能输入坞 Composer 3.0]                    |    18 read-only    |
+------------------+-------------------------------------------------+--------------------+
```

### 2.1 三栏流体 Shell 响应式伸缩
1. **Nav Rail（左栏，宽 180~240px）**：
   - 快速会话切换、历史消息语义检索定位、Agent 模式预设；
   - 窄屏或折叠模式下自动收缩为只保留图标的 48px Mini Rail。
2. **Main Canvas（中栏，主对话区）**：
   - 气泡采用左对齐无边框流式排版（消除传统聊天界面的巨大气泡割裂感）；
   - 正文与 Agent 执行流自然平铺，支持单栏全屏沉浸（Focus Mode）。
3. **Inspector Drawer（右栏，按需展开 260~320px）**：
   - 实时呈现 Token 用量环形图、Prompt 缓存命中率、记忆变量、工具审计日志。

## 三、Agent 工作流与时序可视化演进

### 3.1 树状/节点式执行时间线（Timeline 2.0）
```
  ╭─ 💡 深度思考 (4.2s) ────────────────────────────── [已耗时 4.2s ∨]
  │  "我需要先检查 test 目录下是否存在子文件夹..."
  │
  ├─ ⚡ 工具执行 (Step 1/2) ─────────────────────────────
  │  ├─ 🔍 获取收藏夹列表 `get_collections`              [ 24ms · 成功 ]
  │  │  └─ 返回结果：找到 2 个目标收藏夹
  │  │
  │  ├─ ⚠️ 权限拦截确认 `delete_collection`             [ 等待确认 ⏳ ]
  │  │  └─ [确认卡片: 删除 test8, test9 · 仅本次 ∨]
  │  │
  │  └─ 🗑️ 批量删除 `delete_collection` (x2)            [ 120ms · 成功 ]
  │
  ├─ 💡 深度思考 (1.1s) ────────────────────────────── [已耗时 1.1s ∨]
  │  "删除操作已全部成功，现在向用户汇总结果..."
  │
  ╰─ 📝 任务完成回答
     已为您成功清理 test 收藏夹下的 2 个子项。
```

### 3.2 节点卡片特性
* **状态微徽章（Micro Status Badges）**：
  - 读操作：`🔍 读`（浅灰底蓝字）
  - 写操作：`✍️ 写`（琥珀底橙字）
  - 危险/破坏：`⚠️ 危险`（珊瑚红半透明底）
* **Inline Diff 预览**：对于修改剪贴板条目或模板的操作，卡片内支持一键展开 GitHub 风格的双栏/行内代码 Diff 对比。
* **时序锁机制**：后置思考段严格排布在前置工具执行节点之后，杜绝时序倒挂或内容穿透抢跑。

## 四、输入区 Composer 3.0 升级

### 4.1 悬浮智能输入坞（Floating Smart Dock）
```
+----------------------------------------------------------------------------+
| 📎 上下文胶囊: [📋 当前选中 3 条剪贴板] [📂 收藏夹: 工作组] [⚙️ 代理模式]  |
|                                                                            |
| 输入指令或提示词，支持 / 快捷指令，@ 引用剪贴板条目...                      |
|                                                                            |
| [/compact 压缩历史] [✨ 总结] [🌐 翻译]          [💡 高思考 ∨]  [🚀 发送 ⏎]|
+----------------------------------------------------------------------------+
```

### 4.2 核心特性
1. **多模态上下文药丸（Context Pills）**：
   - 拖入图片、文档、选中剪贴板条目时，输入框上方生成可一键移除的悬浮胶囊标签；
   - 悬停药丸可浮动预览条目内容缩略图。
2. **Slash Command 弹出菜单（`/` 触发）**：
   - `/compact`：手动触发当前会话上下文压缩瘦身；
   - `/clean`：快速发起剪贴板去重与历史清理；
   - `/mode agent` / `/mode ask`：一键快速切换代理执行模式。
3. **`@` 引用中枢**：
   - 输入 `@` 调起剪贴板条目与收藏夹快速模糊搜索，选中即可将条目上下文无缝送入 Prompt。

## 五、深度思考面板与流式呈现精修

### 5.1 极简终端式思考折叠卡片（Reasoning Block）
* **流式中（Streaming）**：
  - 左侧呼吸光点（Purple Aura Pulse）+ 顶部精细进度条；
  - 顶部显示：`💡 深度思考 · 12 秒`（严格等宽数字，消灭重复文字与重排抖动）；
  - 打字机输出采用平滑帧同步（`requestAnimationFrame`），去掉容器 `transition: all`，消除跳动。
* **流式结束（Done）**：
  - 自动平滑过渡为单行紧凑摘要：`✓ 深度思考 12s`；
  - 点击整行丝滑展开查看完整推理链。

## 六、权限请求与安全门控卡片

### 6.1 磨砂玻璃权限拦截卡片（Raycast / macOS 风格）
```
+----------------------------------------------------------------------------+
| 🛡️ 破坏性操作确认                                                          |
| Agent 申请执行具有数据删除影响的操作：                                     |
|                                                                            |
|   操作工具: delete_collection                                               |
|   目标对象: 收藏夹 "test8" (ID: 9e0ec869...)                                |
|   影响范围: 将连带删除该收藏夹下的 14 条剪贴板数据                          |
|                                                                            |
|                            [ 拒绝 Esc ]  [ 仅本次允许 ∨ ] (Enter)         |
|                                          ├─ 仅本次允许 (单次)              |
|                                          ├─ 本会话始终允许 delete_collection|
|                                          └─ 本会话始终允许所有操作 (免打扰)|
+----------------------------------------------------------------------------+
```

### 6.2 快捷键与视觉安全分级
* `Enter`：默认触发主操作（仅本次放行）；
* `Esc`：秒速拒绝并中断危险操作；
* 红色微光外阴影（Red Rim Light），明确警示数据销毁等级。

## 七、子代理与多轮派发抽屉

### 7.1 并行子任务网格（Sub-agent Grid Cards）
* 当调度多代理并发处理（如批量分析多份文档）时，中栏呈现多卡片并发泳道；
* 每个子代理卡片具备独立的进度环、任务摘要、用时与状态指示器；
* 点击卡片平滑滑出右侧独立抽屉，查看该子代理内部完整的 ReAct 推理日志与工具调用链。

## 八、上下文管理与记忆中枢可视化

### 8.1 上下文占用环形仪表盘（Context Gauge）
* 在底部状态栏常驻微型环形仪表盘：
  - `🟢 24%`（安全区间）
  - `🟡 75%`（临近压缩阈值，提示可手动 `/compact`）
  - `🟣 压缩中`（背景平滑扫光过渡，无感替换较早历史并注入记忆要点）

### 8.2 记忆中枢面板（Memory Drawer）
* 直观展示当前对话持久化的用户偏好标签（如“编码偏好 TypeScript”、“语言偏好中文”）；
* 支持用户手动增删修剪记忆片段，让 AI 越用越懂用户。

## 九、微交互、动效与触觉反馈规范

1. **零布局偏移（Zero Layout Shift）**：
   - 所有动态文字（秒数、Token 数）强制采用 `font-variant-numeric: tabular-nums`；
   - 折叠面板展开/收起采用 CSS `grid-template-rows: 0fr -> 1fr` 方案，避免硬编码 `max-height` 导致的卡顿。
2. **物理缓动曲线**：
   - 弹窗与下拉菜单采用 Apple 风格缓动：`cubic-bezier(0.16, 1, 0.3, 1)`；
   - 交互反馈时长控制在 `120ms ~ 200ms` 之间，兼顾轻快感与细腻度。

## 十、实施落地路径建议

* **阶段一（当前已完成）**：时序逻辑加固、多段思考与工具交替编排、确认下拉菜单功能闭环、计时修复；
* **阶段二（视觉全面换装）**：按照本方案落地 CSS Token 变量、时间线节点卡片样式与 Composer 3.0 输入坞；
* **阶段三（高级交互演进）**：接入 `@` 剪贴板中枢引用、Inline Diff 查看器与 Inspector 实时审计抽屉。
