## 三、确认真实有效的功能（实测证据）

- **鉴权/RBAC**：dev 固定码登录、whoami 权限清单、13 项 admin.* 权限目录、自定义角色（custom_ 前缀/level 1-99/名称唯一）全链路；自定义角色权限最小化实测（有 audit.view 可看审计、无 configs.manage 改开关 403）
- **超管保护**：admin 删超管 403（权限+触发器双层）、改超管角色 403、停用超管 403（B1 修复后）
- **用户管理**：搜索/详情/停用（会话全吊销+DB 落因）/启用/强制下线（旧 token 即刻 401）/重置 2FA/等待名单审批（409 幂等）
- **设备管理**：统计/列表/远程下线（原因必填+审计+仅在线可下线+重复下线 400）
- **订阅/订单/套餐**：赠期切套餐+期末计算正确、部分退款/全额退款/重复退款拦截/超额拦截、对账报告 3 渠道汇总与 DB 一致、套餐改价落库
- **审计日志**：所有敏感操作自动留痕（super_admin_action 中间件+业务审计双写）、按 action/操作者/结果/IP/日期筛选、CSV 导出（标准 Blob 下载）、敏感操作红色标注
- **功能开关**：切换写审计+WS 广播+客户端快照即时变化+**服务端强制拦截实测**（关 enable_public_sharing → shared-links 403"共享链接功能已由管理员关闭"）——这是两端客户端未适配情况下唯一但**真实有效**的强制链路
- **公告下发**：落库+历史+delivered_count 准确（=受众用户数）
- **GUI**：登录（倒计时/欢迎提示）/九页面/详情抽屉/各弹窗全部真实数据渲染

## 四、遗留问题（未修复，需产品决策/条件具备后处理）

1. **公告链路客户端侧缺失**：`admin_announcements` 只有管理端写入/查看，**移动端/桌面端无拉取路由、无消费代码**——"下发"实为"记录"。delivered_count 是受众数而非真实触达。需补：客户端公告 API（`GET /api/app/announcements`）+ 两端展示 UI + 真实触达计数。
2. **功能开关客户端 UI 感知未实现**：移动端/桌面端均无 `GET /api/app/feature-flags` 拉取与 WS `feature_flags.updated` 监听（代码级确认）。当前体验 = 功能入口仍显示、点击时被服务端 403 拦截（文案友好）。管理台设置页文案已如实注明"未适配的客户端由服务端兜底拦截"。
3. **试用语义不一致**：trial 订阅 `trial_end=+7天` 但 `current_period_end=+1个月`，无到期强制降级任务——试用用户实际获得 1 个月权益。
4. **设备"远程下线"仅 DB 标记**（代码 TODO 注明）：不吊销同步凭证、不断 WS——设备端可继续同步，仅管理台显示离线。需接 WS 断连指令+凭证吊销。
5. **角色无删除接口**：`DELETE /admin/roles` 不存在，自定义角色创建后不可回收（DB 手工可删）。
6. **真机跨端实测待执行**：审计期间 adb 无设备连接。设备接入后建议执行：① 管理端踢下线 → 真机同步中断并回登录页；② 关 `enable_ai_agent` → 真机 AI 功能报错文案验证；③ 停用账号 → 真机登录被拦截提示。
