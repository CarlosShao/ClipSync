01REALTIME SYNC

一个剪贴板，
所有设备。如此而已。

没有「发送」按钮，没有中转站 App。复制这个动作本身，就是跨设备传输的开始。

1.1毫秒级到达

WebSocket 长连接直推目标设备。验证码这类「错过就作废」的内容，永远赶得上粘贴的时机。

1.2验证码自动接力

手机收到短信验证码，无需手动复制——通知到达即同步上电脑剪贴板，直接粘贴登录。

1.3离线队列

断网时照常复制粘贴，内容进入本地队列，联网后按序补同步，一条不丢、次序不乱。

1.4图片与文件

电脑截图直达手机相册，最大 50MB 的文件分块直传。跨设备传输从此不需要数据线与网盘。

06FAQ
换了新手机，剪贴板和密钥怎么办？＋
新设备扫码配对时通过加密握手安全接入；旧设备可随时在其他设备上移除。历史记录随账号在密文状态下同步到新设备（按套餐上限）。
服务器能看到了我复制的内容吗？＋
不能。内容在设备上完成 AES-256-GCM 加密后才上传，服务器全程只见密文。这也是我们敢把「安全」写进产品第一屏的原因。
iOS 什么时候支持？＋
iOS 在路线图中。当前 Windows / macOS / Linux / Android 已就绪，订阅在各端通用。
如何取消订阅？＋
在客户端「订阅」页一键取消，当期结束前仍可继续使用，之后自动回到 Free，数据不会丢失。
有学生或开源开发者优惠吗？＋
有的——凭教育邮箱或 GitHub 开源主页联系我们，可申请 Pro 免费额度（名额有限）。
