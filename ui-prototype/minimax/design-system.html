06 · 动效

两套曲线：ease-out（标准缓出）用于内容过渡，spring（弹性）用于抽屉/侧栏。3 档时长：160ms（hover）、240ms（标准）、380ms（显著）。

/* 标准过渡 */ transition: all 160ms var(--ease-out); /* 弹性动效（侧栏/抽屉）*/ transition: all 240ms var(--ease-spring);
